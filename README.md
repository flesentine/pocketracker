# Pocket Tracker

A phone-first classic tracker prototype for composing MOD-style patterns with simple Web Audio synth voices.

## Run locally

```bash
python3 -m http.server 8002
```

Then open `http://127.0.0.1:8002/`.

## Features

- 64-row pattern editor with four tracker channels
- Swipe row navigation
- Long-press cell note picker
- Sample voices for kick, snare, bass, and lead
- BPM control with slider
- Demo pattern loader
